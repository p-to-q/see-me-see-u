# 54 · Transformation Causality —— 它怎样变，仍然让人知道是自己让它变

> 这不是一份“再加几种效果”的清单。它回答一个更硬的问题：三分钟以后，身体已经不像你，
> 为什么观众仍然能在一秒内确认“刚才那一下来自我”？
>
> 本页接在 `docs/40` 的“永远不脱钩”、`docs/44` 的零件替换与 `docs/18` 的身体方案之后。
> 冻结契约 `docs/03`、`docs/04`、`packages/core/src/types.ts` 不动；实现中的数仍只进
> `packages/core/src/tuning.ts`。

---

## 0 · 裁定

变化有四条彼此独立、但按同一条时间轴推进的线：

1. **材料在变**：零件逐件被换掉；
2. **局部关系在变**：任何可见部件都可能暂时脱离、再以原件或新件回接；
3. **动作映射在变**：同一次动作可以由另一条肢体、另一种方向或幅度回答；
4. **身体形态在变**：人的拓扑逐渐漂向物种自己的身体方案。

四条线不能再用同一种“把东西拆开”的画法。尤其是：

- **实时因果是底，不是一个会被后期效果覆盖的模式。** 骨盆 / 躯干与动作起点始终读当前观众；
- **骨架因果永远连着。** 可见零件可以离开，但实时骨架和当帧 socket 仍是唯一载波；不做自由刚体或另一段动画；
- **所有部件有资格，不等于全身同时炸开。** 第一件由手建立语法；末端、肢段、核心逐段开放，核心稀有且独占；
- **脚可以离开，但承重信息不能说谎。** 单脚事件只收掉该骨段覆盖的接触阴影 / 触地声，另一只脚与四足的其余支点继续；事件有向上弧线且两脚不并发；
- **静止不自演。** 除非观众明确按下 `untether`，宏观动作必须在观众停下后一起停；
- **先修身份，再做陌生。** 前二十秒是可靠、灵敏的人形镜子；没有这一步，后面所有变化都读成故障。

这里的“同拍不同形”不是让机器自己播放另一段动画。输入动作的**起点、能量包络和停止时刻**
仍与观众同拍，变化发生在“由哪条链回答、朝哪边回答、回答多大”上。

## 1 · 当前实现为什么会被读成坏了

### 1.1 四十秒不是一个问题，是两条旧设计正好叠在一起

`?arc=90` 时，物种形态漂移从 `0.47 × 90 = 42.3s` 开始；`orb` / `furball` 又会自动选择
`radial`，而这套旧方案明确允许两条腿自由漂浮。默认三分钟弧线的同一事件是在 84.6 秒左右，
因此“约四十秒身体和脚分开”要先记录当场 `arc / species / plan`，不能只归因给一个随机 seed。

另一条同时存在的路径是忒修斯：20–40 秒第一段优先替换 `foot / joint / clavicle`。前者改变拓扑，
后者改变材料，但现在两者都可能被画成“连接断了”，观众无法区分作品变化与工程故障。

新的裁定是：`radial` 可以改变四肢朝向和身体轮廓，但不能再把仍被画成“腿 / 脚”的承重链变成
无来源的漂浮件。短期先把旧 `radial` 从自动弧线隔离，只留在开发预览；修复时用现有第一段腿骨做
hub tether，不新增骨头、不改冻结骨架契约。若物种需要卫星状末端，也必须先在视觉上完成从“脚”
到非承重器官的变形，不能在一次 blend 中突然断开。

### 1.2 零件替换把“换材料”画成了“每一处都能肢解”

`THESEUS.quietSlots` 目前把脚、关节、锁骨列为第一段优先项；`replace-event.ts` 又给**所有槽位**
同一套旧件碎开、新件从骨轴外吸回的动画。于是头四十秒里最容易发生的，恰好是承重或连接部位
短暂离位。代码可以证明轮廓没有洞，却不能证明观众不会把它看成脚与身体断开。

这不是把 `shardSpread` 调小就能解决的问题。材料替换与肢体脱离需要两套明确的视觉语法：

| 部位 | 默认替换 | 脱离语法 |
|---|---|---|
| 手 / 脚 / 头 | 原位换 | `terminal-release`；手先建立语法，单脚不与另一只脚并发 |
| 锁骨 / 上臂 / 前臂 / 大腿 / 小腿 / 颈 | 原位换 | `segment-release`；成本更高，不能和另一段同时散开 |
| 脊柱 | 原位换 | `core-release`；最晚、最小幅、独占预算 |
| 关节 | 十三处仍共享同一个 Genome pick | 每次只点名一个稳定 joint 名脱离；最终换件仍遵守共享 pick |

“替换了脚的材料”和“脚从身体上离开后以新件回来”是两件不同的作品事件，代码也分别表达。
前者永远可原位发生；后者必须经过 plan → renderer admit → receipt → commit，容量或安全预算拒绝时不能提前改 Genome。

### 1.3 动作线只有延迟、重量、朝向三个数，缺少“同拍异形”

修订前的 `core/src/line.ts` 只有：整副骨架最多 1.2 秒延迟、临界阻尼重量、左右朝向转移。
`docs/44 §6` 原来写过的幅度、局部错位、前段偏移叠加从未实现。结果是后期最容易得到两种体验：

- 整个人慢一拍，观众觉得“不灵”；
- 整副骨架被连续翻向，观众看见形状改变，却未必读得出哪一下来自自己。

现在已经不再延迟整副身体：当前帧与历史帧先经过同一份空间映射，骨盆、躯干、腿与肘走实时载波；
历史和重量只混入前臂 / 手的方向，再从当前肘按当前骨长向外重建。机器下一步可以用右手回答你的左手、
用抬臂回答你的侧移，但回答仍必须在你动作开始的同一时间窗里发生。

定向步进探针已经把这个体验量出来：输入在 `t=2.0s` 开始，echo 的首个大于 1mm 的响应出现在
`t=3.2s`，正好额外延迟 1200ms；这还没有算 pose clock 约 33ms 的正常采样延迟。这个数不是需要
继续微调的风格参数，而是实时底座必须移除的整体延迟。修订后的同一 200mm 阶跃在第一个显示帧
已经回应 102.2mm；15 / 30 / 60 / 120Hz 四档都在第一帧超过 1mm，历史占比上限为 0.5。

### 1.4 “生命力”的自主呼吸已退出实时骨架

旧 `core/src/vitality.ts` 在能量低时主动加入正弦呼吸，而且越静止越明显；定向探针量到静止输入
胸口自行移动 4.26mm、手尖 18.37mm。这与 `docs/40` 的“站着别动，如果它还在做动作，这条线就破了”
不能同时成立。

现在实时路径只保留由当前动作产生的 follow-through：骨盆、躯干、头、肩、肘与腿逐帧取当前输入，
只有肘后的前臂 / 手方向保留短余势；静止 200 秒的 `vitality → Director` 正式顺序实测全链 0.0000mm。
自主运动只属于观众明确交还身体后的 `untether`，同一夹具 20 秒能量到 102.9mm。材质、团块与空场
仍可呼吸，但不能搬动正常交互中的宏观关节。

### 1.5 现在测了骨长和预算，没有测“观众看到的连接与地面”

现有测试能证明骨长、预算、描边和骨架落地；用户报告仍出现了拖地与入地。这说明验收对象不完整：
必须同时量最终骨架关节、部件挂载矩阵和实际几何 AABB。一个骨架点在地上，不等于零件的最低面在地上；
一根骨头长度正确，也不等于替换动画没有把那件视觉上移出插座。

这里已经有可复现的工程证据：`assemble.ts` 把替换芯、墨屑和新件的效果几何一并算进全身最低点。
使用真实 `parts.json` 做一次 `joint` 同件换同件，在 `t=0.65` 时，未替换的头也被整体抬高
33.2mm。落地算法正在用短暂特效搬动主体，因此会产生上下泵动；遇到形态 blend 第一帧又立刻切换
目标 plan 的落地基准时，跳动会进一步放大。

不同新旧件的定向回归又把两种失效分开了：`wheelleg → screenface` 的左脚在交接结束
时会让主体单帧跳 45.29mm；真实 GLB accessor AABB 上的 `wheelleg` seed 92、tier 2→3、
`quadruped` 右手作为承重前足时，终帧也会跳 40.664mm，而过程中可见新手最低点一度在
地下 74.335mm。`parts.json` 与真 GLB 的最大 AABB 差只有 0.033mm，所以这不是元数据失真，
而是“主体落地基准”与“短命效果几何如何碰地”两条规则都没写完。

全身 remorph 还曾有第三种时间线错误：系统先把 `genome` 指向最终目标，但同时只有两个描边槽位
能进入 active。porcelain seed 11 tier 1→2 一次改了 11 个槽位，其中 9 个排队槽位会
先直接画新件，轮到时又回到旧件，然后再正式变新。现在队列明确保留画面状态：
未激活的槽位画 `Swap.from`，目标 `genome` 只回答“最后去哪里”，不再冒充“此刻在哪里”。

已有定向测试 103/103 通过，只说明旧规则被忠实实现：目前的“永不脱钩”测试没有把
`bodyPlan + vitality + assemble + capture` 串在一起，也没有扫描最终几何。新验收必须补这一层，
不能把旧测试全绿当成现场体验已经成立。

## 2 · 产品弧线：一条连续线，不是四个突然换挡的效果

下面是观众该读到的顺序，不是四个新的状态机：

| 时间窗口 | 观众读到什么 | 技术上的主变化 |
|---|---|---|
| 0–20 秒 · 认出 | “它就是我，而且很跟手” | 人形、实时脊柱、零全身延迟；材料和拓扑不抢戏 |
| 20–50 秒 · 第一处疑问 | “刚才是不是有一件东西变了？” | 材料原位替换；第一只手建立离开—回接语法 |
| 50–95 秒 · 回声 | “还是我的节奏，但局部关系变了” | 末端逐步开放；实时躯干 + 局部历史余波 |
| 95–145 秒 · 异形 | “它已不是人形，但仍然在回应我” | 肢段与稀有核心事件可达；`bodyPlan` 连续漂移 |
| 145–180 秒 · 共动 | “它和我同时动，却不做同一个动作” | 所有部位都有可能性；输入动作包络和 socket 仍实时 |

时间窗口沿用现有三分钟弧线的意义；生产数落地时仍由 `tuning.ts` 唯一提供，不能在实现里复制一张表。

## 3 · 最小可维护架构

不建 ECS、不建事件总线、不做插件框架。只把现在已经混在一起的三种职责分开。

### 3.1 `line.ts` 继续做唯一动作映射器，但变成“双路响应”

保留 `createLineSampler()` 这个现有边界，不另造第二套导演。内部明确分为：

1. **live carrier**：当前帧的骨盆、胸与动作起点；
2. **expressive mapping**：局部延迟、左右 / 跨肢体路由、幅度与阻尼；
3. **chain rebuild**：从父关节按既有骨长重建子链，保证每条链仍接在插座上；
4. **diagnostics**：暴露 live / echo / route 的实际权重，给 HUD 和取证，而不是再靠肉眼猜参数。

映射器已经由每个 `Director` / encounter 实例持有，不再放在模块全局。`reset()` 接到换观众、换主身份、
reacquire 与 untether 往返；输入停滞仍由 sampler 自己截断。失败或坏值时返回 live carrier，
而不是返回上一个人的变形结果。两个 Director 同进程交错、四种 reset 边界与缺 runtime 降级已有测试。

脱钩玩法自身也遵守同一条所有权边界：`ACTS` 只登记原型，有跨帧状态的 Act 通过
`instantiate()` 给每个 Director 一份私有闭包。`untether` 的进入姿态与相位不再是模块全局；
因此未来双屏、多人或远程协作可以并行运行，而不会让后一具身体偷走前一具身体的基准。
它的频率、幅度、高度权重和卡顿步长集中在 `UNTETHER` tuning 块，换声音或段落节奏时无需改控制流。

### 3.2 零件层接一份 `DetachmentPlan` 和一张真实 receipt

这不是共享协议，不改冻结的 `SlotKey` / `Genome`。app-local 计划只有三个正交事实：

- `profile`：`in-place` / `terminal-release` / `segment-release` / `core-release`；
- `result`：当前替换链已经实现 `transform`（旧件离开、新件回接），`return` 留给未来同件事件；
- `member`：只有 `joint` 使用，存稳定 joint 名，不把数组下标当持久语义。

计划不携带任意向量、米数、时钟、概率、落地开关或 tether 开关。阶段、概率、相对骨长位移、向上弧线和加权预算
统一从 `THESEUS.detachment` 读取；随机来自 encounter seed 派生的独立 `Rng`，不会改变玩法 Rng 的调用序列。
第一次可见脱离固定由手建立；之后所有槽位按阶段和注入随机获得非零机会。两次脱离之间保留原位事件，避免画面成为钟表。

事务顺序写死为 plan → `Creature.replace()` validate / capacity / detachment budget → receipt → commit：

- renderer 拒绝、同件 no-op 或容量不足时，不改 Genome、不记 `swapped`、不响声音、不消费策略；
- profile 无效、两脚冲突或加权预算不足时，本次材料变化可降为 `in-place`，receipt 记录真实 applied；
- 在途事件永不再作为 capacity victim；满了宁可不开始，也不让半空零件突然消失；
- 主身份交接只撤掉旧人的脱离位移，保留旧 / 新件当时的交接进度在 socket 上继续；不能删掉半程事件，让半空 / 半尺寸零件瞬间跳成满尺寸；整场 Genome 与弧线保留；
- 伴随身体共享换件进度但永远原位，不复制主身体的脱离。

渲染仍只改已有实例矩阵，不新增桶或 draw。骨头件按当帧骨长外移并叠一个小的世界 +Y 弧线；既有墨屑在脱离时
分布到 socket→零件之间，作为短暂关系线。关节只让计划点名的一个 cap 离开，其余盖片按原 joint wave 原位变化。
所有 profile 与交接共用归一化进度，两端严格回 socket；remorph / graft 同样已取消隐式飞入，缺省原位长回。

### 3.3 落地只保留一个最终修复点

最终骨架在 `bodyPlan → vitality/follow-through` 之后统一交给 `bodyplan.ts/groundSkeleton()` 修一次地面；
`vitality` 不再持有第二套 plan 参数或落地规则。两端各自落地不代表中间插值落地：修前
`rig → inverted` 在 0.25 / 0.50 / 0.75 会悬空 292.5 / 645.0 / 322.5mm；现在六种 A 档方案的
0.01 / 0.25 / 0.50 / 0.75 / 0.99 中间态都在最终收口后回到 y=0。渲染层只再验证部件几何最低点。

规则：

- 有脚方案以承重脚链为地面；无脚方案以整具最低点为地面（沿用 `groundsByLowestJoint`）；
- 主体落地只测稳定的身体几何；替换芯、墨屑、飞入 / 飞出件等短命效果不得参与主体根高度；
- 替换动画不改变骨架承重插座；支撑骨段脱离时只按槽位过滤它覆盖的端点，另一只脚 / 其余支点继续，视觉件有向上弧线并逐件 floor clamp；
- 任一非有限输入、未知 plan 或修复失败，退回上一副合法骨架；帧循环不抛。

主体基准现在不再把旧件 AABB 用到事件最后一帧：每个正在交接的槽位都用新件已有的 `graftCurve`
在旧 / 新满尺寸代理的世界最低点之间连续插值，然后再与其余稳定身体取全局最低点。
真实 `wheelleg → screenface` 脚部 1.2s / 60Hz 回归把 45.29mm 终点跳变收成最坏
0.943mm/帧，终点逐位等于正常新身体。落地和视觉长回来只有一条缓动语义，以后调交接节奏不需要同步第二套曲线。这只完成了主体基准；上面量到的可见手部穿地仍要由
短命效果自己的规则处理，不得反过来搬动主体。这条也已经落地：主体完成稳定 lift 后，
每个 `groundsBody=false` 的实例各自测 AABB，只在最低点穿地时沿 +Y clamp 自己。
`wheelleg` seed 92、tier 2→3、`quadruped` 右手交接从最深 −74.335mm 收到 121 个阶段
全部不低于地面容差；头部矩阵与“不画效果、只用同一稳定代理”对照逐位一致。

### 3.4 给声音与未来联机的是语义，不是另一副骨架

以后声音或实时线上协作要接，只暴露低频语义：动作起点、能量、被路由的肢体、替换 / 脱离事件与弧线位置。
不要让声轨或网络成为第二个逐帧骨架消费者。这样主循环断网照跑，远端跟不上时丢事件或取最新值，
不会反压摄像头与渲染。

## 4 · 验收：同时证明实时、变化与不坏

### 4.1 纯逻辑

- 任意坏 `dt`、NaN、空关节、未知方案不 throw；输出有限；
- 每根输出骨的 `p1` 与子骨 `p0` 在数值误差内相接，骨长不漂；
- 静止输入两秒后，除追踪噪声外不再产生宏观关节位移；
- 所有 SlotKey 都有可达 profile；第一次非原位事件仍是手，阶段前与概率未命中时原位；
- 末端成本低，肢段 / 核心独占加权预算；两脚不并发；同 seed 的决策与时间线逐位相同；
- `joint` 一次只点名一个 cap；未知 member / 错 profile 退原位；
- 动作映射故障时，同一帧退回 live，不等待、不排队。

### 4.2 回放 / 浏览器

每个代表物种跑 0 / 40 / 90 / 135 / 180 秒五个切片，并额外跑 `?arc=90` 的 40–45 秒窗口，记录：

- 输入动作起点 → 屏幕首个可见响应的 runtime 增量不超过两个显示帧；
- 端到端输入到画面延迟以目标机器实测：正常路径 p95 不高于 120ms，15Hz 降级不高于 180ms；
- 最终骨架和真实部件几何都不低于地面容差，承重接缝没有可见空隙；
- 任一窗口都不越加权预算；早段先手，脚 / 肢段 / 核心只在各自阶段与概率门之后可达；
- 180 秒时做十次左右 / 上下 / 开合动作，至少八次能指出“哪一下由刚才哪一下而来”；
- `?theseus=off`、未知部件、占位几何与低性能降级都仍能完成整条路径。

### 4.3 真人

真人不是“看一眼觉得还行”。固定三组距离、顺 / 逆光与快 / 慢动作，逐项问：

1. 五秒内是否认出“这是我”；
2. 第一次变化读成“在变”还是“坏了”；
3. 后期是否仍觉得它在当下回应；
4. 有没有脚断、肢体拖地、主体入地或整具失去重心；
5. 停住后，它是否也停住。

任何一项失败，先收回到更实时、更连接的版本；不以“这是艺术效果”解释故障感。

## 5 · 实施顺序

1. **复现，不猜。** 用当前 seed / theme / arc 录下 40 秒与入地案例，HUD 同步记替换 slot、line 参数与 plan；先固定 `?arc=90` 复现 42.3 秒 radial 切入；
2. **先止血。** `radial` 暂离自动弧线；承重 / 连接槽位改原位替换；效果几何退出主体落地测量；关闭 live 路径的自主关节呼吸。其中 **radial 自动路径隔离**、**特效 / 主体落地分离**、**新旧稳定代理的 AABB 基准连续插值**、**忒修斯缺省原位替换**、**短命效果逐件碰地 clamp**、**自主关节呼吸隔离**与**骨架最终统一收地**已经落地；仍欠 remorph / graft 中承重 / 连接槽位的原位语义与真人可见链回归；
3. **再修因果。** 实时载波、局部方向余波、方向级重量、chain rebuild 与 per-Director 状态已经落地，旧 `follow` 仍是永久 fallback；
4. **建立全槽位语法。** DetachmentPlan / receipt、原位缺省、全槽位 profile、单 joint cap、预算 / 冲突、主身份收尾与脚接触语义已落地；真人仍要决定概率和幅度是否可读；
5. **现场定标。** 通过上面的真人矩阵后，再调整范围和概率，不用合成姿态替观众做审美决定。

这五步可以逐个提交、逐个回退。任何一步都不要求下一步存在，现场版本始终有一条完整、实时、连着地面的路径。

## 6 · 明确不做

- 不把每个物种做成一套独立动作系统；
- 不让生成模型、网络或声音进入实时骨架路径；
- 不用更多随机事件掩盖弧线无聊；
- 不让“所有部件有资格”退化成“所有零件替换都默认脱离”；
- 不为了未来协作先建通用 EventBus / ECS；
- 不在没有真人时间线证据前继续调延迟、弹簧或 spread 常数。
