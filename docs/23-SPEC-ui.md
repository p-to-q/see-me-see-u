# 23 · SPEC · UI —— 每个场景，每个状态，每个边界情况

> 一条总规矩：**每多一个 UI 元素，都要论证它为什么不该被删掉。**
> 这件作品的气质是影棚，不是仪表盘。观众来看的是那具身体，不是我们的界面。
>
> 第二条：**观众永远不该看见"出错了"。** 所有失败都要降级成一个说得通的画面。

## 0. 视觉语言

> **实现在 `packages/app/src/ui/type.css`，这一节是它的说明。**
> 度量取自 zkm.de 线上 CSS（2026-09-12 实测）：body 1.0rem/400/1.5，
> h1 2.00rem/1.15/600，h2 1.50rem/1.25/600，html 100%→105%。
>
> **字体**：`ZKMSerendipity`（Regular/Medium + Italic，228 KB，`font-display: swap`），
> 出处与授权基础见 `assets/fonts/ZKMSerendipity/NOTICE.md`。
> 回退栈 `Helvetica Neue → Neue Haas Grotesk → Suisse Int'l → Univers → Arial → system-ui`，
> **两种情况下排版度量完全一致**，所以字体没到时不会有回流跳动。
> `?font=system` 可以强制走系统栈，用来确认这一点没骗人。

| | 值 | 理由 |
|---|---|---|
| 底色 | `#0E0F12`（近黑，不是纯黑） | 纯黑在投影上会和关机分不清 |
| 前景文字 | `#9AA0A6`，强调 `#DFE4EA` | 不用纯白：纯白会和身体的高光抢注意力 |
| 强调色 | 取当前条目 `palette` 的 accent | UI 跟着物种走，而不是有自己的品牌色 |
| 字体 | 正文 grotesk 系统栈；**数据/标注用等宽** | 数字要能对齐，这是「档案感」的来源之一 |
| 字号 | 正文 1rem / 小号 0.8125rem / h2 1.5rem / h1 2rem | 三级以上就开始像后台系统 |
| 字距 | h1 −0.02em、h2 −0.01em、全大写标签 +0.08em | grotesk 大字号要收紧、小字号要放开 —— 这套风格最容易被忽略的一半 |
| 文案长度 | 单行 ≤ 14 字，全场景总字数 ≤ 60 | 现场没人会读第二行 |
| 动效时长 | 进 240ms / 出 180ms / 移 420ms / 过场 1200ms | 出比进快，符合直觉。「移」是换页时字标、巨题、目录那个词、页脚图从上一页的位置挪到这一页（docs/47 §4）：它走的是一段距离，不是一次出现。令牌在 `type.css`（`--sb-dur-*`），和 `ui/transitions.ts` 的 `MOTION` 逐字相同 |
| 缓动 | 进 `cubic-bezier(.16,1,.3,1)`，出 `cubic-bezier(.4,0,1,1)` | — |
| 边距 | 屏幕安全区 ≥ 48px（投影会切边） | 现场真的会切掉 |

**禁止**：加载转圈、toast、模态框、图标按钮、阴影卡片、圆角面板。
这些都是"应用"的语言，不是作品的语言。

> **2026-09-13 修订：「进度条百分比」从禁止清单里去掉了。**
>
> 原来的判断是对的一半：一个**圆角的、会动的进度条**确实是应用的语言。
> 但它被当成了"任何形式的进度都不许有"，于是几 MB 的冷启动期间观众对着黑屏，
> 而黑屏和「坏了」在观众眼里没有区别 —— 这是整条路径上最容易流失人的一刻。
>
> 现在允许的是**档案的语言**：一条 1px 的细横线 + 一个等宽 tabular-nums 的数字。
> 和选择页那条 30 秒倒计时线、和 `/making` 的坐标栏是同一个构件。
> 仍然禁止的是圆角、渐变、条纹、转圈、"正在加载…"的省略号动画。
> 实现见 `packages/app/src/shell/loading.{ts,css}`，两条硬规矩写在那个文件头里：
> **进度必须来自真实信号**，**没有真信号的地方宁可停住也不许编**。

### 动效的一条硬规矩：入场动效不许决定"看不看得见"

带 `animation-fill-mode: both` 的入场动效，等于把元素的静止态设成 `opacity: 0`，
只有动画跑完才变成 1。而动画**不一定跑**：文档时间线没有推进的页面上
（无头浏览器、被降到后台的标签页）它会停在 `playState: running / currentTime: 0`，
于是那个元素永远透明 —— DOM 在、字在、人看不见，而且控制台一声不吭。
本轮实测踩过一次（`shell/notice.ts` 的那一行）。

所以：**出场动效随便用，入场动效不许承担可见性**。要淡入就让静止态是可见的那一侧。

## S0 · Boot（启动 / 自检）

正常路径：**观众不该看见这个场景**——直接进 S1。

| 边界情况 | 表现 | 为什么这么设计 |
|---|---|---|
| WebGPU 首次 pipeline 编译卡顿（0.5–2s） | 底色，**不显示任何文字**（加载态有 600ms 宽限期，这个尺度上它一帧都不画） | 有文字反而强调"在等" |
| 冷启动 0.6 秒以上，**没有展签的那条路**（深链、`?demo=1`、现场） | **加载态**：字标一开始是**大的**（画面中段，放大 2.3 倍），420ms 后左下角三档才展开 —— `正在点亮画面` / `正在准备零件` / `正在认识你的身体`，各自一个真实百分比，底下一条 1px 的总进度线。露过面就至少露 900ms（`MIN_SHOW_MS`），缓存命中导致的"一闪而过"不再发生；三档**真的**到齐之后再停 1000ms（`DONE_HOLD_MS`）。退场分三步，每一步等上一步做完：细节先收起（240ms）→ 字标从大变小挪到选择页/`/about` 那个最终角落位置（420ms）→ 到位闪一下（200ms）→ 这一层才整个摘掉，没有淡出。选择页的 anchor 图此刻已经到齐，但 DOM、输入和卡片 reveal 都还没开始；`finish()` 在节点真正移除后 resolve，下一帧才由选择页接手（`shell/loading.ts` / `ChooseOptions.beforeReveal`） | 观众该知道**现在在等什么**，不只是"还要多久"。一个笼统的百分比说不出前半句。显示权是一道闸门，不是靠透明底色幸运遮住后一页；任何一帧只能有一个 UI 主体 |
| 冷启动 0.6 秒以上，**有展签的那条路**（网页版默认） | 加载态**不挂字标**（`mountLoading(flags, { hasEntry: true })`）——只有百分比、三档、进度线。字标的"大变小"动画已经是展签自己的事：按「开始」时巨题会 `morph` 成选择页的字标（`entry.ts`）。加载态如果也来一遍同样的动画，观众会同时看见两份 SEE-ME SEE-U 叠在一起（2026-09-15 真人测出来的） | 一份动画只属于一条路。两条路各自的字标动画分开看都对，叠在一起就是没人分得清哪个才是真的 |
| WebGPU 不可用 → WebGL2 回退 | 现场：静默。网页：右下角一行 `降级渲染` 4 秒后淡出（`shell/notice.ts`，2026-09-13 落地）。**在加载态收掉之后才说** —— 说早了会被那一层盖住，等它露出来 4 秒早走完了 | 现场没人能处理这个信息；网页用户可能会换浏览器 |
| `parts.json` 缺失 | 静默用占位几何。**绝不提示"资源加载失败"** | 占位几何是合法的 tier 0 形态，本来就是作品的一部分 |
| 单个 glb 失败 | 该槽位用占位件，其余正常 | 观众看不出少了一件 |
| 冷启动 > 8 秒（慢网） | 加载态底下多一行人话：`再等一下，网有点慢`。20 秒后换成 `还在等。第一次打开要下最多东西，之后会快很多` | 说"超时""重试"是运维的词，观众听到它只会走开 |
| 加载途中发生降级（`sb:degrade`） | 那一行换成 `画面会简单一点，它照样会动起来` | 观众读到的是**结果**，不是"降级"这个词 |
| 冷启动 > 8 秒（慢网，粒子版） | 粒子团缓慢聚拢成人形轮廓（本身就好看） | 把等待变成预告。**未实现** —— 目前慢网上是加载态那三行，不是粒子 |
| 启动真的失败（异常抛到顶层） | 满屏底色 + 居中一行 `稍等一下` + 控制台详情 | 观众看到的是一句人话，不是堆栈 |
| `?selftest=1` | 逐条打勾的检查列表（WebGPU / 摄像头 / 资产 / 回放片段） | **只给我们自己用**，现场开场前跑一遍 |

## S1 · Attract（空场）

一团在地面上缓慢呼吸的粒子。**不是黑屏**——黑屏会让观众以为机器坏了。

| 边界情况 | 表现 |
|---|---|
| 无人 5 分钟 | 降到 30fps，粒子更慢。**画面不熄** |
| 有人经过但没停留（< 0.4s） | 粒子有极轻微的偏转（像被风带了一下），不进 S2 |
| 多人经过 | 同上，只跟面积最大的那个 |
| 现场灯光突变导致追踪闪烁 | `presence` 的 0.4s 滞回吸收掉，不闪进闪出 |
| 连续运行数小时 | 粒子的呼吸相位由累计时间驱动，不会"回到起点"露出循环 |

**文字**：现场无。网页版底部一行 `站到画面里` / 或一个 `打开摄像头` 按钮（见 S0 网页分支）。

## S2 · Choose（选物种）

竖直螺旋上的卡片，远离的溶解成有序抖动。卡片图 = 该条目自己的 anchor 渲染。

| 状态 | 表现 |
|---|---|
| 正常 | 中心卡清晰，两侧渐次模糊 + dither |
| 悬停/聚焦 | 中心卡上方一行：`物种名` + `一句 tagline`，**不超过一行** |
| 选中 | 卡片冲向镜头 → 溶回抖动 → 直接进 S3。**没有确认按钮** |

| 边界情况 | 表现 | 理由 |
|---|---|---|
| 某条目没有 anchor 图 | 用程序化卡片（该物种的几何轮廓在抖动里浮现），**不显示破图** | 破图会立刻毁掉整个气质 |
| 条目被 `clearance` 挡住 | 根本不出现在列表里，螺旋自动收紧 | 不能留空位——空位会被当成 bug |
| 可选条目 < 3 个 | 螺旋退化成横向一排 | 3 个以下的螺旋看起来像坏了 |
| 无 WebGL | DOM 降级列表：**同样的排版语言**（等宽字、同底色、卡片图），不是丑陋兜底 | 降级路径也是作品的一部分 |
| 30 秒无操作 | 最后 5 秒中心卡下方出现极细的进度线，走完自动选中 | 没有倒计时的话，突然跳转会吓到人 |
| 观众在选择中途走开 | 倒计时照走，自动选中，进 S3，然后由 `presence` 自然回落 S1 | 不需要特殊处理 |
| 卡片图还在下载（这一页真正的等待） | S0 的加载态继续走「正在准备零件」那一档，分母是 anchor 图张数；图到齐后加载层完成 100% 停留与退场，然后才挂选择页 DOM 并启动螺旋 reveal | 资产下载仍然并行；`onProgress` 上报真进度，`beforeReveal` 只序列化可见 UI，不增加一段猜出来的等待 |
| 输入方式 | 触摸滑动 / 鼠标滚轮 / 方向键 / 数字键直选 / 遥控器（映射到方向键） | 现场可能只有遥控器 |
| 条目 > 10 个 | 数字键只映射前 10，其余靠滚动 | 别做分页 |

## S3 · Enter（进场）

卡片溶解 → 身体出现。**这一刻必须无缝**：卡片的抖动直接变成身体的抖动。

| 边界情况 | 表现 |
|---|---|
| 该物种的部件还没加载完 | 先用占位几何成形，真件到货后**逐件淡入替换**，不整体重建、不闪 |
| 摄像头还没就绪 | 身体先以 tier 0 的原始形态站着轻微呼吸，追踪到人后接管 |
| 观众在过场动画中走开 | 动画照常演完，然后 `presence` 走 LEAVING → S1 |
| 过场超过 1.2 秒 | 不允许。资产没到就用占位，**时间不许被资产绑架** |

## S4 · Live（共舞 · 核心场景）

**默认零 UI。** 满屏只有身体、地面、影子。

| 例外（允许常驻的元素） | 触发 | 理由 |
|---|---|---|
| 左下角 `物种名`，极低对比度 | 进场后 4 秒淡出，此后不再出现（`shell/notice.ts`，2026-09-13 落地） | 观众需要知道自己选的是什么，但只需要知道一次 |
| 演化进度：地面影子外缘的一圈极细弧线 | 常驻，但几乎看不见 | 它不是仪表，是"这个身体在积蓄什么"的暗示 |
| 左下角那块**实时读数**（`ui/readout.ts`，2026-09-14 落地） | 网页版常驻；**现场默认不挂**，要它就写 `?readout=on` | 这件作品的整条链是一具身体被一台机器**读**成数，而观众只看得见结果——于是那次翻译读起来像魔法，而"翻译一个人要付出什么代价"正是它的题目。这一块把那次翻译摊开：置信 / 关节 / 推理 Hz / 动能 / 舒展。**它只装测量，不装作品的决定**——乐章、进度、档位、忒修斯换到第几件一个都不上来（docs/40 §5、docs/23 §S5、docs/44 §7）。它是这一屏唯一一处允许有边框和圆角的东西，因为它必须读作**不是作品**；完整的 §F 论证在 `ui/readout.css` 的文件头 |
| 左上角「它有没有看见我」小屏幕（`ui/preview.ts`，2026-09-13 落地） | 网页版常驻；**现场默认不挂**，要它就写 `?preview=on`；`?demo=1` 永不挂 | 「默认零 UI」的前提是**它真的在动**。追踪垮掉时身体只是站着不动，而那和"作品坏了"在观众眼里是同一个画面 —— 这一块把那件看不见的事变成看得见的。它**顺利时一个字都没有**，所以它没有违反上面那条，它是那条规矩的前提条件 |

| 边界情况 | 表现 | 理由 |
|---|---|---|
| 追踪短暂丢失 < 1s | 保持最后姿态，加极轻微的 idle 漂移 | 完全静止会读成"卡了" |
| 追踪丢失 > 1s | 进 S7 溶解 | |
| 多人入镜 | `?people=1`（默认）：MediaPipe `numPoses=1`，**它给的是检测器排第一的那个人，不保证是面积最大的** —— 这一行原来的"跟面积最大的那个"在单人档上从来没被实现过。`?people=2\|3`：每人一具身体，超过上限时按面积、带滞回换人，主身体走了交给台上已经有身体的人，身体进出走在场的长出 / 缩回，不瞬移（docs/50） | 瞬移会读成 bug；"谁拿到身体"必须不闪（docs/50 §7） |
| 观众太近（全身不入镜） | 地面上出现一条极细的位置线 + `往后一点`，2 秒后无论如何淡出 | 这是唯一一句功能性文案，必须短且会自己消失。**未实现**（2026-09-13 走查）：`COPY.live.stepBack` 写好了但没有调用点；"全身不入镜"的判定在 `stage/framing.ts`，那条线这轮不归 UI 动 |
| 观众背对 | 照常跟随（背面姿态一样能驱动） | 不做特殊处理 |
| 极端姿态（倒立/躺下） | 挂载数学已保证不产生 NaN；身体跟着倒 | 这是彩蛋不是 bug |
| 帧率跌破 45 | 自动降级：先关后期，再降实例上限，**不提示观众** | |
| 连续 30 帧渲染异常 | 回落占位几何；再失败则重载页面 | 观众看到的是身体变简单了，不是报错 |

### S4.1 · 右上角「控件」：默认开着什么、按钮能做什么、面板上留什么（2026-09-14，作品负责人裁定）

网页版才有（`?kiosk=1` / `?nav=0` 一个像素都不挂）。代码：`ui/control-table.ts`（每个控件的唯一来源）、
`shell/intent.ts`（叠加）、`ui/controls.{ts,css}`（视图）。

**默认值一个都没改。** 下表同时抄在 `ui/controls.ts` 文件头；表里的默认和 `readFlags('')` 读到的一致由 `test/control-table.test.ts` 核对。

| 项 | 默认 | 谁改 | 在哪改 |
|---|---|---|---|
| 描边 | 物种自己声明（「线」开，其余关） | 观众 | 「看起来」· O；`?shading=` |
| 跟随延迟（生命力） | 开 | 观众 | 「看起来」· D；`?vitality=0` |
| 声音 | 开 | 观众 | 「看起来」· M；`?mute=1` |
| 时域精化 | 开 | 做对照的人 | 「对照」（最底下）· R；`?refine=0` |
| 后期 | 开 | 做对照的人 | 「对照」· P；`?nopost=1` |
| 忒修斯换件 | 开 | 现场操作员 | `?theseus=off`，不在面板上 |
| 三分钟弧线 | 开，自己走完四段 | 观众可以在上面叠 | 「玩法」「形体」的第一项「跟着弧线」· A / F |
| 读数 | 收起 | 观众 | 左下角自己点开，不在面板上 |
| 取景 | 自动（坐近 → 上半身中景，退后 → 等身全景；docs/49 §5） | 观众 / 做演示的人 | 「取景」· C；`?framing=auto\|full\|upper`。全身 / 上半身是叠加，选「自动」就交回分类器 |

**没有一个按钮能锁住系统。** 每一项要么是一个变量的开 / 关（描边、延迟、声音、精化、后期、画面），
要么是**叠在弧线上的一条**（玩法、形体）。叠加的规矩：弧线在底下照走（elapsed / 乐章 / 档位 / 换件都不停）；
**再点一次亮着的那一项就拿掉**，所以每一项都是自己的解除键；第一项「跟着弧线」就是"什么都没叠"。
以前「玩法」调 `director.force`、「形体」写一个永远赢的 `planOverride`，按一下弧线就停在那一段，只有重载能解。
玩法叠加换的是线的**采样点**（`core/src/line.ts` 上那个地名），不是让时间停下；为什么不是"钉住 N 秒自己松开"写在 `shell/intent.ts` 文件头。
重载、回大厅、随机只在叠加**真的开着**时写 `act=` / `plan=`；随机不抽玩法（弧线自己会走完四段）。人一走，叠加回到 URL 写的那一份。

**面板上留什么、显示什么、删了什么。**

| | 内容 | 理由 |
|---|---|---|
| 留 | 形体、画面、玩法、看起来（描边 / 延迟 / 声音）、物种、随机 | 观众会选的，每一项按下去当场看得见 |
| 留，挪到最底下 | 对照（精化 / 后期），字小一档 | 真开关，工程上做 A/B 用；观众不需要先看见它们 |
| 留 | 快捷键条（从表里推） | ` 和 X 只在这里写着 |
| 显示 | 叠加组里：亮着的是你叠的（只有实线，不配文字）；弧线此刻走到的那一项标「此刻 · Now」；面板顶上一行汇总 | 观众要知道不点也有东西在走，以及怎么撤回。**不显示秒数和乐章号**：docs/40 §5 不给观众看进度（状态表见下） |
| 显示 | 开关格右边「开 / 关」 | 同上 |

| 删 | 随机组的第二句说明（和组说明重复）、没人用的 `reload` 文案、「渲染」这个组名 | 说两遍的话、没有调用点的字 |

**没有底（作品负责人裁定：面板全透明）。** 选项格原来是不透明的纸色、格线是"行底色从缝里露出来"，暗场景上是一块补丁。
现在面板、格子、筛选框一样底都没有：字、线、键帽、选中线全部跟右上角的墨（`--sb-*-tr`，采样器按角底下的像素翻）；
格线是每格自己的 1px 边，颜色是右上角说明墨兑一半。代价照写：墨按角落平均亮度挑，身体从某一格底下走过时那一格会暂时读不清。
`test/controls-surface.test.ts` 量采样器在纯黑、纯白、五套场景上会挑的那套墨：字与说明 ≥ 4.5:1、选中线 ≥ 3:1、格线看得出且和选中线分得开；
没有一处 `background` 底色（先对原来的不透明版跑红：4 条全红）。

**状态表**（没有底之后，状态只靠墨的强弱 + 线的形状 + 一个等宽小字说；每一种都有一条不是颜色的差别，同一个测试钉住）：

| 状态 | 记号 | 说明 |
|---|---|---|
| 可按 | 名字和说明都是常墨（说明小一档）、格子一圈兑淡的线 | **字一律不用暗墨**：没有底之后 `--sb-ink-dim` 在白展厅上只有 3.39:1（测试红过一次）；层级改由字号说 |
| 悬停 / 键盘焦点 | 名字下 1px 实线、格底边提到常墨 | `:focus-visible` 同一个记号，不用鼠标也看得见 |
| 选中（开关开、画面选中、叠加选中、「跟着弧线」在用） | 名字最强墨 + 2px 实线、格底边最强墨；开关格写「开 / 关」 | `aria-pressed` |
| 弧线此刻 | 名字下 1px **点线** +「此刻 · Now」 | 不点也有东西在走：每秒跟着弧线挪。`aria-current` |
| 叠加 | 选中的记号，**不配文字** | 作品负责人 2026-09-14：格子里的「叠加 · 再点撤销」是累赘，删掉。叠了什么由面板顶上那一行和收起时的「叠加 N」说 |
| 弧线此刻与叠加落在不同格 | 两个记号同时在 | 「线在这儿，我把它推到了那儿」 |
| 刚按下 | 名字下 3px 实线，150ms | 纯叠加，没有过渡，静止态不依赖它（1.7 fps 那条教训） |
| 重开中（换物种、进出团块、随机） | 「重开中 · Restarting」+ 等待光标，面板不再接按键 | `aria-busy` |
| 这具身体上没有 | **不出现** | 不画成灰的 |
| 链接 | 一行字 + 常驻底线，和正文链接同一种样子 | 读作"去别处"，不读作选项 |

面板顶上一行等宽小字：「此刻 · Now 回声 Echo　叠加 · On top 四足 Quadruped」；有叠加时收起的节题后面写「叠加 N」，面板关着也看得出这一屏被推过。**不写秒数和乐章号**（docs/40 §5）。

**面板不压右下角那一列**：`ui/exits.ts` 把列高写到 `--sb-exits-h`，面板的 max-height 减掉它。

**加一个控件**（和 `ui/control-table.ts` 文件头同一份）：

1. `CONTROLS` 里加一条：种类（toggle / overlay / choice / action）、组、键、`url.write`、`fromFlags`；
2. `ControlValues` 里加它的值类型；
3. `COPY.controls` 里加文案（缺哪句 `control-table.test.ts` 会点名）；
4. `main.ts` 的 `controlValues()` 读它、`set()` 写它 —— 接到那个已经存在的变量上；
5. 它会改弧线拥有的东西吗？会，就做成 overlay 进 `shell/intent.ts`，不许写一个会赢过弧线的变量。

## S5 · Evolve（升档瞬间）

不是独立场景，是 S4 里的**事件**。必须可感知，否则演化等于没发生。

- 时长 **600ms**：全身一次极轻的脉冲（亮度 +8%）+ 时间轻微停滞（0.15s 内 dt ×0.4）
- 变化的槽位**逐件**换装，最多同时 3 件，其余排队
- 同时一声低频确认音
- **没有文字、没有等级数字、没有 "LEVEL UP"**

| 边界情况 | 表现 |
|---|---|
| 阈值附近来回 | `tuning.ts` 的滞回 + 2 秒冷却挡住 |
| 一次要换 18 个槽位 | 排队播完（约 7 秒），期间观众仍可正常互动 |
| 降档 | **不做视听事件**。悄悄退回去 —— 失去不该被庆祝 |

## S6 · Slow loop（你的零件长出来）

作品的差异化时刻。全程 **只有一个 UI 元素**。

| 阶段 | 表现 |
|---|---|
| 触发（进场 20 秒后，每人一次） | 无提示。静默把剪影送出去 |
| 生成中（30–90s） | 身体的**某一个槽位**开始极缓慢地明灭 —— 就这一个信号 |
| 到货 | 该部件从骨轴外 0.15m 吸附回位 + 一声确认音 |
| 失败 | 明灭停止，恢复原状。**观众永远不知道失败过** |

延迟不是缺陷，是叙事：*它正在想怎么成为你*。所以**不要进度条、不要"生成中…"文案**——
那会把一个诗意的等待变成一次加载。

### 「那不是坏了，是有人先来过」——`docs/43 §9.8` 的那一句

一个从存档链接进来的人看到的是：作品自己在动，而摄像头是黑的。
不说明，他会以为坏了；说明得太重，就变成一个 UI 控件。
`docs/43 §9.8` 裁的是**一句话，不加控件**，这一节是它的登记处（边界情况归这份文档管）。

**定下来的那一句**（常量在 `ui/i18n.ts` 的 `COPY.lineage.replay`，中英并置走 `setBi`）：

> 循一条存档链接回到作品，画面会自己动起来，摄像头不亮 —— 那不是坏了，是有人先来过。
>
> Follow an archive link back into the piece and it moves on its own, with the camera
> dark. Nothing is broken: somebody was here before you.

规矩，和裁定逐字对应：

| | 规定 | 理由 |
|---|---|---|
| 位置 | `/lineage` 的正文里，**画面之外**，和那一页其它文字同一列 | 它是这一页的一句话，不是覆盖在作品上的一层 |
| 语域 | 照 `/lineage` 现有的那一套（`ln-note`），和 `emptyBody` / `offBody` 同一个音量 | 那一页对"空"和"不存在"已经各有一句有分量的话，这是第三句 |
| **不做** | 角标、「回放中」的常驻标记、任何播放/暂停 | **那是播放器的语言，而这件作品不是播放器**（裁定原话） |
| 出现时机 | 只在存档那一支（`/api/visits` 有内容）渲染 | 没有存档就没有存档链接，那时候说这句话是在描述一件不存在的事 |

## S9 · 目录（网页版才有的那一个元素）

站点有**七**个可见面：`/`、`/about`、`/making.html`、`/passport.html`、
`/lineage.html`、`/dev/`、`/poster/*`。（`/lineage` 是后加的那一个，
它是唯一一个内容不由仓库决定、而由前面的观众决定的面。）
在这一节存在之前，**首页上一个入口都没有**，而且这些页面之间一条链接都没有 ——
一个评委打开首页，除非有人当面告诉他，否则永远不会知道 `/about` 和 `/making` 存在，
而那两页承载了这件作品一半的表达。

| | 规定 | 理由 |
|---|---|---|
| 位置 | **右上角** | 左上角已经被占了三次（`ui/page.ts` 的浮层页头、`?debug=1` 的 HUD、2026-09-13 起还有 `ui/preview.ts` 那块小屏幕，HUD 已为它让到 `top:224`）。右上角在所有页面上都是空的 |
| 收起态 | 一个词 + 一条细线：`目录 CONTENTS`。没有图标、没有汉堡 | 和入口层的 `.sb-act` 是同一个构件 |
| 展开态 | 一张表：名字 + **一句"它能回答什么问题"**，行间细横线，当前页标 `在这里` | 人不是在找功能，是带着疑问来的。`/dev/index.html` 已经验证过这个写法 |
| 语言 | 中英并置，不切换 | `src/ui/i18n.ts` 的设计决定 |
| 现场（`?kiosk=1`） | **根本不挂**。判断只有 `readFlags().nav` 一处 | 装置画面上不该有网站导航（§S4「默认零 UI」） |
| 满屏画布页 | 4 秒后淡到 0.18，鼠标碰上/键盘 tab 到就回来 | 和浮层页头同一条规矩、同一个数 |
| 文档流页面 | 常驻不淡出 | 那几页本来就是拿来读的 |
| 关掉 | `?nav=0` | 「投影但不是 kiosk」那种场合 |
| 入口展签之上 | 目录 z-index 11 > 展签 10 | 展签**就是网页版的首页**，目录不在这里等于不存在 |
| 当前页那一条 | 渲染成 `<span>` 而不是灰掉的 `<a>`，并带 `aria-current="page"`（2026-09-14，docs/47 §5） | 一条点了什么都不会发生的链接，比没有链接更让人怀疑坏了；排版上的退一档读屏看不见 |

实现：`packages/app/src/ui/nav.{ts,css}`，文案在 `ui/i18n.ts` 的 `COPY.nav`。

### S9.1 · 侧室：**故意不进目录**的那几个房间（2026-09-14）

上面那张表管的是**面**。侧室不是面，所以它一条都不进这份名单 ——
七个面仍然是七个，加了三个侧室之后还是七个。

**什么是侧室。** 三个：`/parts`（部件档案）、`/roster`（物种接触表）、
`/marks`（九枚记号）。它们原本都是我们自己的仪器，回答的是工程问题。
它们被展出的判据只有一条：**它回答的那个问题，一个没造过这件作品的人也有。**
「这件作品到底长出了什么」「它一共能变成哪些身体」「那九种身体凭什么算九种」——
这三句话观众问得出来，所以这三个房间开着。其余十四页不开（名单见 `/dev/index.html`）。

| | 规定 | 理由 |
|---|---|---|
| 不进目录 | 目录只列面。侧室是**某一面上的某一句话被说到底**的样子 | 把它们列进去，目录就从"这里有什么"退化成"这里有哪些 URL"。一份会长到十一条的目录，没有人会读完 |
| URL | 根目录下的真页面：`/parts` `/roster` `/marks`，和 `/about` 平级 | 一个展出的房间必须在线上有稳定地址。`/dev/*` 读起来是后台（而且**整棵树本来就进 dist** —— vite 扫两个目录，见 `vite.config.ts` 的 `pages()`），把观众送进去等于告诉他他走错了门 |
| 怎么进去 | **线索**：`/about` 正文里的数字。一个可以被穷举的数，通向它的穷举 | 「物种 28」→ 那 28 张卡；「身体方案 9」→ 那九枚记号；「部件 230」→ 那 230 件；编号对照表里每一个号 → 那个物种在部件档案里的那一格（`/parts#t-<id>`）。「槽位」「材质」**没有门** —— 不是每个数字都通向什么，所以它不是一个"把数字都做成链接"的手势 |
| 线索的静止态 | 和周围的字**逐像素相同**：没有下划线、没有换色、没有图标、没有 `cursor: help` | 一扇看得出是门的门不是线索。`.ed a` 那条常驻的 1px 底线在这里被摘掉了 |
| 线索被摸到 | hover 与 `:focus-visible` **走同一条规则**，就是这个站每一条普通链接的那一条（强调色底线从左长出来），外加浏览器自己的焦点环 | 发现一扇门的回报应当是"哦，它是个链接"，不是一套只在这里出现的新语汇。焦点环**不许关掉**：正文里的一条 1px 底线说不清"焦点在这儿" |
| 读屏 | 每扇门都带一段视觉上不存在、读屏念得出的目的地（`COPY.rooms.doors`）：「28 侧室 · 物种接触表 链接」 | **一扇对辅助技术不可见的暗门不叫含蓄，叫坏了。** 代价是读屏用户比看得见的人更早知道门在哪 —— 两害相权，"有人更早知道"远比"有一类人永远进不去"轻 |
| 一个都没被发现 | 这几页仍然完整 | 门只开在**本来就存在**的数字上，不为开门往正文里加一个词。`ui/clue.ts` 的 `clue()` 只接受调用方已经建好的节点，所以这条是被实现挡住的，不是靠自觉 |
| 横带 | 侧室**也戴**（`ui/hero.ts` 的 `heroMeta`），默认指向 `/about`，字写「返回作品陈述」（2026-09-14 前写的是「回到作品」，和目的地不是一件事）；带合法 `?from=`（含 `/dev`）进来时回来处 | 从正文里一个数字点进来的人，屏幕上一条出去的路都没有。指 `/about` 不指首页：那才是他刚才站的地方。`test/page-header.test.ts` 钉住 |
| 目录 | 侧室上**挂**目录，收起（2026-09-14 改，docs/47 §5） | 原来不挂，理由是"地图挂在第八个房间的墙上会让人以为走错了"。那条理由成立的前提是人从 `/about` 正文进来；从工作台点进来的人屏幕上只有一条回 `/about` 的路，负责人读到的是"去不了别的页面"。目录里没有侧室，当前页那一条也就不亮 —— 它不说侧室是第八面 |
| `/dev/index.html` | 侧室在那一页上**是列出来的**（「侧室」那一组） | 那一页是后台的地图，给我们自己看。对维护的人瞒着这三个 URL，换不来任何含蓄，只换来下一个人 grep 不到 |

实现：`packages/app/src/rooms/{room,parts,roster,marks}.ts` + `ui/clue.{ts,css}`。
文案在 `ui/i18n.ts` 的 `COPY.rooms`。

### S9.2 · 旁注：正文里相关的字，通向**目录外**的仪器（2026-09-14，作品负责人裁定）

**规矩放宽了，放宽的是哪一半。** 上面那条"门只开在正文里本来就有的、可以被枚举的数字上"
管的是**侧室**，它不变：数字仍然是通向它的穷举的门（`ui/clue.ts`，静止态隐形）。
作品负责人觉得只有这一种门太窄 —— 工作台上有好几页本身就值得给人看（他举的例子是
"选一个材质、一点就生成各种零件"的那一页），它们出于策展理由**不进目录、不是展品**，
但目录里那几页（`/about` `/making` `/passport` `/lineage` 和侧室）的正文说到相关的事时，
**那几个字可以直接链过去**，必要时允许补一句话来挂这个链接。所以现在有第二种门：

| | 线索（`ui/clue.ts`） | 旁注（`ui/asides.ts` + `ui/aside.ts`） |
|---|---|---|
| 挂在哪 | `/about` 正文里一个可以被穷举的数 | 任何正文页里**本来就在**的一个短语，中英各一处 |
| 通向 | 侧室（那个数的穷举） | 工作台上的某一台仪器（`dev/*.html`） |
| 静止态 | 与周围逐像素相同 | 就是 `.ed a`：常驻 1px 底线，摸到时强调色从左长出。**不加类名、不加样式** —— 它不假装是暗门 |
| 回去 | 侧室横带默认回 `/about` | 链接带 `?from=<这一页>`，目的地印「返回〈那一页〉」并指回去；Escape 同一个目标 |

## S10 · 文档流页面在窄屏上（`/about` `/making` `/passport` `/lineage`）

一条规矩：**宽的东西在自己的容器里横向滚，页面本身永远不横向滚。**
被裁掉的正文和有滚动条的正文是同一件事的两种表现，所以
**`overflow-x: hidden` 不算修好** —— 它只是让溢出不再报信，字照样读不到。

这四页靠**六件具体的事**成立，六件都在 `packages/app/test/narrow-viewport.test.ts`
里有守卫（node 验不了版面，所以它验的是这六条在样式表文本上还成不成立，
每一条附它拦的那一种坏法）：

| | 规定 | 没有它会怎样 |
|---|---|---|
| 版心边距 | `.ed` 的 `--ed-edge: clamp(20px, 4.2vw, 60px)` | 用固定的 `--sb-safe`（48px）会在 320px 上吃掉三分之一 |
| 满幅线 | `.ed-rule` 的 `margin: 0 calc(var(--ed-edge) * -1)` | 两处只改一处，这条线在**每一个宽度**上都捅出视口 |
| 塌栏 | 窄屏断点里一律 `minmax(0, 1fr)` | 裸 `1fr` 的最小宽度是 min-content，一条长路径就顶开它 |
| 正文格 | `.pp-row__body` / `.ed-section__body` / `.ln-row__body` 的 `min-width: 0` | grid 子项默认 `min-width: auto`，同上 |
| 巨题 | `.sb-display` 的 `overflow-wrap: anywhere` | 「SEE-ME SEE-U」捅出视口（`type.css` 记过这一次） |
| 存证列 | `.sb-evidence li` 的 `word-break: break-all` | `packages/factory/src/index-parts.ts` 这样的路径顶开右栏 |

### 实测（2026-09-14）

版面只有浏览器量得出来，所以数记在这里，不在测试里编。
本机 dev server 与 `vite preview` 打的 dist 两套，Chromium，
每个宽度上遍历整棵 DOM 取 `getBoundingClientRect().right`，
并对每一个文本节点取 `Range.getClientRects()`：

| 页面 | 量过的宽度 | `documentElement.scrollWidth` | 右边越过视口的盒子 / 文字 |
|---|---|---|---|
| `/passport` | 300 / 320 / 360 / 380 / 400 / 420 / 440 / 460 / 480 / 500 / 520 / 560 / 600 / 620 / 700 / 780 / 860 / 900 | 每一档都 **= 视口宽** | **0 / 0** |
| `/about` | 300 / 360 / 420 / 500 / 620 / 700 / 780 / 860 / 900 | 同上 | **0 / 0** |
| `/making` | 300 / 360 / 420 / 500 / 620 / 700 / 780 / 860 / 900 | 同上 | **0 / 0** |
| `/lineage` | 300 / 360 / 420 / 500 / 600 / 760 / 800 | 同上 | **0 / 0** |

`/passport` 另外单量过：目录展开时 `scrollWidth` 仍是 420；
420px 上 `.ed` 的内容右边界是 400，越过 400 的文本行 **0 行**。

复现用的片段（贴进 DevTools 控制台即可，不引任何依赖）：

```js
const vw = document.documentElement.clientWidth;
const boxes = [...document.querySelectorAll('*')]
  .filter((el) => el.getBoundingClientRect().right > vw + 0.5);
const texts = [];
const walk = document.createTreeWalker(document.body, NodeFilter.SHOW_TEXT);
for (let n; (n = walk.nextNode()); ) {
  if (!n.nodeValue.trim()) continue;
  const r = document.createRange(); r.selectNodeContents(n);
  if ([...r.getClientRects()].some((c) => c.right > vw + 0.5)) texts.push(n.nodeValue.trim());
}
console.log(document.documentElement.scrollWidth, vw, boxes.length, texts.length);
```

> 记一句，免得下一轮再查一遍：本轮是带着"`/passport` 在 500px 以下横向溢出、
> 四枚章的正文都被右边裁掉"这条报告来的，**照上面的办法量下来没有复现**。
> 最像的一种成因是**截图本身**：页面按 800px 排版、图被裁到 420px 宽，
> 读起来就是"每一段正文都在右边被切掉"，而且四枚章切得一模一样 ——
> 真的溢出很少会在四段长短不同的文字上切得一样齐。
> **先量再判**：`scrollWidth` 和视口宽是一个数就是没溢出，截图不是判据。
